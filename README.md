# arthurdouradodev / site

Site pessoal e portfólio de **Arthur Camargo Dourado**. No momento, uma landing page "em construção".

## O que tem aqui

- Fundo de planta baixa (blueprint) com partículas de "poeira de obra" que fogem do cursor
- Nome que se monta letra por letra e subtítulo digitado
- Cards com efeito de inclinação para [GitHub](https://github.com/ArthurDouradoDev/) e [LinkedIn](https://www.linkedin.com/in/arthur-camargo-dourado/)
- Barra de progresso da obra (dá para assentar tijolos 🧱)
- Terminal interativo (`help`, `sobre`, `github`, `linkedin`, `status`, `build`...)
- Um easter egg escondido (dica: código Konami)
- Respeita `prefers-reduced-motion` e funciona no celular

## Rodando localmente

É HTML, CSS e JS puro, sem build:

```bash
python3 -m http.server 8000
# abra http://localhost:8000
```

## Publicando

Pronto para GitHub Pages: em **Settings → Pages**, escolha a branch e a pasta raiz (`/`).
